技能职责与路由

将工具选择、批量提取和本地浏览器执行拆成三个技能约定，按静态页面、动态列表与人工登录页面选择执行通道；路由由 Agent 读取规则后执行。

DOM 提取与持久化

使用原生输入框 setter 和 input/change 事件，轮询列表标识后按字段白名单提取；以 Set 去重、逐页写入 localStorage、分段导出。

规则预检

Python 将标题噪声、重复号码前缀、重复邮箱与来源集中度拆成独立函数，返回结构化告警；持久化快照与人工复核分别保留。

合成夹具验证

三组各 12 行的合成数据通过 4 项断言。合法单来源样本仍会触发集中度提示，规则用于复核，不输出真实性或准确率保证。
