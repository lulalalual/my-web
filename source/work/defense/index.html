双人塔防

C++ / SDL2 / WebAssembly · 双输入、状态机与浏览器移植。

C++SDL2WebAssemblyEmscripten

开发方式基于公开 C++ / SDL 学习工程，完成浏览器适配、修复与双人扩展。

技术实现在原有实体、地图与波次系统上扩展两组独立输入、技能和能量状态，并适配浏览器主循环、键盘与触控。

正在准备项目…

浏览器移植

使用 Emscripten 将 C++ / SDL 工程编译为 WebAssembly，复用原地图、实体资源与关卡逻辑，连接浏览器画布及输入事件。

双输入与生命周期

为两个角色拆分输入、技能与能量状态；在页面隐藏和离屏时暂停实际 WASM 主循环，处理暂停、重开和恢复。

实现来源与验证

基于 Village TD 公开教程工程完成适配、修复与扩展；原代码、美术与音效归原作者。实测两位角色移动、全屏、波次及暂停恢复。
